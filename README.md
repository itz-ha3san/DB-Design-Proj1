## راه‌اندازی

1. PostgreSQL را نصب و اجرا کنید.
2. یک پایگاه داده خالی ایجاد کنید؛ برای مثال:

   ```sql
   CREATE DATABASE chinook;
   ```

3. فایل `data/chinook.sql` را روی پایگاه داده‌ی ایجادشده اجرا کنید. برای نمونه با `psql`:

   ```bash
   psql -U postgres -d chinook -f data/chinook.sql
   ```

   در صورت نیاز، نام کاربر و پایگاه داده را متناسب با تنظیمات خود تغییر دهید.
4. برای مشاهده پاسخ‌ها، فایل گزارش PDF را از مسیر `docs/` باز کنید.

> **نکته:** اسکریپت `chinook.sql` شامل دستورهای ایجاد جداول و درج داده‌های نمونه است؛ آن را روی یک پایگاه داده خالی اجرا کنید. اگر قبلاً جداول ساخته شده باشند، ممکن است خطای تکراری بودن اشیا دریافت کنید.

تمرین شامل ۲۰ پرسش تحلیلی در چهار حوزه است:
